# Splat

Splat is a generative art program built with Scenic and Elixir. Each time you run it, it creates a unique piece of art featuring flowing bezier curves with colorful triangles.

## Running

To generate new artwork:

```bash
mix deps.get
mix run --no-halt
```

## Features

- [x] Generative bezier curve art
- [x] Random triangles along curves  
- [x] Unique artwork every run
- [x] Cross-platform with Scenic
- [x] Mathematical precision drawing
